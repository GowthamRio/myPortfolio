# Portfolio Project

This workspace contains a React portfolio app and a deep React masterclass tailored for experienced Angular developers.

## React Masterclass

A complete Angular-to-React transition guide is available in [REACT_MASTERCLASS.md](REACT_MASTERCLASS.md).

It covers:
- React internals and architecture
- Angular-to-React comparisons
- project creation with Vite, CRA, Next.js, and Remix
- enterprise project structure
- hooks, state, routing, forms, APIs, testing, performance, and deployment
- interview-ready explanations and common mistakes

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
